The Perceptron Formula

The neuron first builds a weighted sum, then passes that sum through an activation function. Written as symbols:

z = (X1 × W1) + (X2 × W2) + biasy = f(z)

Step function
If z ≥ 0, output = 1. Otherwise output = 0. When z is exactly 0, NeuroPlay follows this rule and returns 1.
Sigmoid function
1 / (1 + e−z). The result is always between 0 and 1. Large positive z moves toward 1, and large negative z moves toward 0.
ReLU function
max(0, z). Positive sums pass through unchanged. Zero and negative sums become 0.

Understand the Calculation

These steps use the sliders above. Products are shown with ordinary decimal rounding, and z is the exact sum of those slider values.

  1. Step 1: Multiply inputs by weights.

    X1 × W1 = 1 × 0.5 = 0.5

    X2 × W2 = 2 × 1 = 2

  2. Step 2: Add bias.

    z = 0.5 + 2 + (-1)

    z = 1.5

  3. Step 3: Apply activation function.

    Since z >= 0, output = 1.

    The step function turns the weighted sum into a yes or no decision. One means class 1. Zero means class 0.

Learn the Building Blocks

The same five ideas show up in larger neural networks. Here they are visible one number at a time.

What is a perceptron?

A perceptron is a basic artificial neuron used for making predictions. It multiplies each input by a weight, adds a bias, and applies an activation function. Frank Rosenblatt described this model in the late 1950s. Networks used today still rely on this pattern, repeated across many units and layers.

What are inputs?

X1 and X2 are the features of one example. For an AND gate they are the two bits, 0 or 1. In this playground they can be any value from -5 to 5, which makes the geometry easier to see. A real model might use hours studied and hours slept, or the width and height of an object. The neuron itself only sees numbers.

What are weights?

Weights decide how important each input is, and whether it pushes the sum up or down. If W1 is large and positive, increasing X1 raises z a lot. If W1 is negative, increasing X1 lowers z. If W1 is 0, X1 does not affect the result. Training a network means adjusting weights. Here you edit them yourself so the effect stays obvious.

What is bias?

Bias is a number added after the weighted inputs. It shifts the decision boundary. Without bias, the line z = 0 always passes through the origin, because zero inputs would always produce z = 0. A negative bias means the inputs must contribute enough positive signal to cross zero. That is why AND uses bias -1.5: one input alone is not enough.

What is an activation function?

The weighted sum is only a number. An activation function decides what the neuron reports. Step is a hard threshold, useful for a first look at binary classification. Sigmoid squashes z into a smooth score between 0 and 1. ReLU keeps positive values and blocks the rest. Nonlinear activations matter even more once several neurons are stacked, because they let later layers build curved patterns.

Limitations of a single perceptron

A single perceptron with a step activation can solve linearly separable binary classification problems. AND and OR are separable: one straight line puts the output-1 points on one side and the output-0 points on the other. XOR is not. XOR is 1 only when the inputs differ, so the two positive cases sit on opposite corners. No single straight line can isolate both of them. Sigmoid and ReLU still depend on one linear sum, so one neuron of this kind cannot solve XOR either. XOR needs extra features or more than one layer.

About NeuroPlay

NeuroPlay is a teaching page for university students and beginners who want to see a single-layer perceptron calculate an output by hand, then on a graph. It shows two inputs, two weights, one bias, and one activation function. It does not train weights, load a dataset, or build a hidden layer.

Use it beside a lecture on linear separators. Set the AND or OR preset, click through the truth table, then change the bias and watch the boundary move. Switch to sigmoid or ReLU and compare a hard 0/1 decision with a graded output.

Educational simulation

This is an educational simulation of one perceptron. It is not a medical, financial, or production machine-learning system, and the sliders are not learned from data. Calculations run locally in your browser.
